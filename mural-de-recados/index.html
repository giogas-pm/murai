O que é o Muraí

O Muraí é uma ferramenta para criar um mural de recados online e coletivo: várias pessoas escrevem mensagens (com foto e emoji) no mesmo lugar, a partir de um único link. No fim, tudo vira uma retrospectiva animada e um PDF — um presente digital feito por todo mundo que ama a pessoa homenageada. Juntar os recados é grátis; você só paga uma vez, se quiser, para desbloquear o presente final.
